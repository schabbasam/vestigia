# Vestigia

A terminal based mystery game written in Rust.

## About

Vestigia is a latin word and means "traces". It sounds cool and kinda fits.
The game is partly just a story, partly a terminal simulation.
You have to solve some riddles by exploring the system, not that difficult.

## Features

I don't really know what I should list here. Just take a look at the code.
I tried to make it understandable. 
Please don't open the source code before playing if you don't want to get spoiled.

## Commands

For a list of the commands in the terminal simulation, just type 'help'.

## Getting Started

### Requirements

You need:
- Rust installed
- a terminal that supports ANSI escape sequences and ideally also colors

### Running from source

- clone this repository
- enter the folder
- 'cargo run'
